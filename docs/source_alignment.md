# 论文源码恢复记录

以作者提供的最终 `paper/ReviewGuard.pdf` 为权威文件；它与工作区根目录同名 PDF 不同。

完整检索现有 TeX 后，最接近的源码为 `6.27_pricai/pricai_final.tex`。它已包含最终的 0.0138 平均 TVD、0.0087 的 20% 基础结果、自然突发诊断和部分自适应攻击，但与最终 PDF 仍有文字及表格差异。原包原样保留在 `docs/source_snapshot/`。

`paper/reviewguard.tex` 是在该源码副本上根据最终 PDF 恢复的版本，变动限于：

- 四条贡献说明与相关工作段落。
- 规模实验段落及最终 PDF 的表 6（数值同时核对 `reports/scale_stress_eval.csv`）。
- 案例结尾的解释句，以及结论中的未来工作句。

方法、参数、现有实验数值、图片和参考文献数据库均按候选源码保留。论文已通过完整 BibTeX 编译流程，生成 16 页本地预览。最终 PDF 与本地编译预览有字体及浮动体排版差异，因此不将恢复源码冒充提交时的确切原始源码，也不覆盖提供的最终 PDF。

此处记录源码与 PDF 的客观差异，不修改原工作目录中的任一论文。
